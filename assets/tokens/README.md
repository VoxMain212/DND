# PNG-фишки

Игра использует прозрачные PNG как вертикальные фигурки на круглых основаниях.

| Файл | Образ |
|---|---|
| warrior.png | Воин |
| mage.png | Маг |
| rogue.png | Плут |
| cleric.png | Жрец |
| skeleton.png | Скелет-сборщик |

Это оригинальные временные иллюстрации проекта. Исходники находятся в `assets/token_sources`, скрипты создания — в `tools`. Они не генерируются во время игры и не требуют модели.

Для замены достаточно положить свой PNG под тем же именем и дать Godot переимпортировать файл. Рекомендуется прозрачный фон, персонаж целиком и минимум пустого пространства по краям. Текущие картинки имеют размер 256×384; другие размеры поддерживаются, фишка автоматически вписывается в область 0,78×1,15 игровых единиц. Для небольших фишек достаточно 256–512 пикселей по ширине.

Изображение поворачивается к камере только вокруг вертикальной оси, сохраняя впечатление стоящей картонной фигурки. При поражении картинка кладётся на карту. Клик по прозрачной части картинки проходит к карте; клик по непрозрачной части выбирает фишку.

Встроенные рисунки передаются как ID образа: чтобы все видели заменённые вручную картинки из этой папки, обновите файлы у всех участников или отправьте им новую сборку. Загрузка произвольных готовых PNG через файловый диалог пока не реализована.

Начиная с версии 0.4 портреты, созданные через «Мастерскую», сохраняются отдельно в `user://portraits` и передаются игрокам автоматически по хешу. Здесь остаются встроенные исходные образы и резервные фишки. Установка настоящих моделей и отличие нейросети от тестового режима описаны в `docs/LOCAL_AI.md`.

Повторный запуск `tools/bake_tokens.gd` перезаписывает эти PNG исходными временными иллюстрациями. Для обычной замены картинки запускать его не нужно.
